# Fase 2 — Produto

Proposta de valor: descobrir lançamentos antes de serem lançados (novidades) e produtores, para não ter preocupação com saturação, com dados verificáveis (nunca inventados).

Público: afiliados profissionais e gestores de tráfego (BR / LATAM / gringa) que vivem de timing.

Posicionamento: "O Bloomberg Terminal dos lançamentos de afiliação."

Diferencial defensável:

- Camada de Evidências (toda info tem fonte + data + confiança)
- Early Signal Score (metodologia proprietária)
- Signal → Verified pipeline (dados limpos)
- Modelo SaaS: Free → Pro → Premium → Enterprise (detalhado na fase de monetização)
